# Sales Tax

Technical challenge: a receipt calculator that applies sales tax and import duty to a shopping basket.

## Constraints

- Pure Ruby only. No Rails or other frameworks.
- External libraries/gems are allowed only for build or testing purposes (e.g. RSpec).
- Ruby version pinned in `.ruby-version` and `Gemfile` (currently 3.3.10).
- All code, comments, commit messages, and documentation must be written in English.

## Workflow

- This is a guided exercise: the user drives architecture and design decisions. Do not make design decisions unilaterally — propose options and wait for direction before implementing.
- `DECISIONS.md` is a running log of architectural decisions made during the challenge. Only add entries when explicitly asked to ("Documente decisões" / "DD:").

## Running

```
bundle install
bundle exec rspec
```
